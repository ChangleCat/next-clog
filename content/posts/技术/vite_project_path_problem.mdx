小特使用的 Vite 版本：`7.1.2`

长话短说，总共三个文件：
> 1. vite.config.ts   （让  vite  知道）
> 2. eslint.config.js （让 eslint 知道）
> 3. tsconfig.app.json（让 vscode 知道）

## vite.config.ts

```typescript
// ...
import path from "path";

export default defineConfig({
  // ...
  resolve: {
    alias: {
      "@": path.resolve(__dirname, './src')
    }
  } // 追加部分
});
```

## eslint.config.js

```javascript
// ...
import importPlugin from 'eslint-plugin-import'; // 自行安装
import { resolve } from 'node:path';

export default tseslint.config([
  globalIgnores(['dist']),
  {
    // ...
    plugins: {
      import: importPlugin
    },  // 追加部分
    settings: {
      'import/resolver': {
        alias: {
          map: [
            ['@', resolve(__dirname, './src')],
          ],
          extensions: ['.js', '.ts', '.jsx', '.tsx', '.json'],
        },
      },
    },
  },  // 追加部分
])
```

## tsconfig.app.json

为什么不是`tsconfig.json`而是`tsconfig.app.json`?

> 因为 tsconfig.app.json 是针对浏览器运行环境的配置[^foo]
